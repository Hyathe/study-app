HOW TO INSTALL AS AN APP
========================

OPTION 1 — Host locally (recommended for PC)
----------------------------------------------
1. Install Node.js from https://nodejs.org
2. Open terminal/cmd in this folder
3. Run: npx serve .
4. Open http://localhost:3000 in Chrome
5. Click the ⊕ install icon in the address bar
6. App appears on your desktop/start menu!

OPTION 2 — Android phone/tablet
---------------------------------
1. Copy this folder to your phone or host it (see Option 1)
2. Open Chrome → navigate to the app
3. Tap ⋮ menu → "Add to Home Screen"
4. Done — app icon on home screen, works offline

OPTION 3 — iPhone/iPad
------------------------
1. Open Safari → navigate to the app
2. Tap Share button (box with arrow)
3. Tap "Add to Home Screen"
4. Done!

OPTION 4 — Quick local server (Python)
----------------------------------------
Open terminal in this folder and run:
  python -m http.server 8080
Then open: http://localhost:8080

IMPORTANT: PWAs only install from http/https — NOT from file://
So you need a local server (any of the options above).
